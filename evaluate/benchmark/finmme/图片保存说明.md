# 为什么需要保存图片？

## 数据流程说明

### 1. FinMME 数据集的存储方式

FinMME 数据集存储在 HuggingFace 上，数据格式为：
- **文本字段**（如 question_text, answer）：直接存储在 Arrow 文件中
- **图片字段**（image）：以二进制格式存储在 Arrow 文件中

当使用 `datasets.load_dataset()` 加载数据时：
- ✅ **不会联网下载**（因为数据已经在本地缓存）
- ✅ 从本地的 Arrow 缓存文件读取数据
- ✅ 图片字段会被自动转换为 **PIL Image 对象**（Python 内存中的图像对象）

### 2. evaluate_py 框架的要求

`evaluate_py` 框架期望的数据格式是：
```json
{
  "question_id": "0",
  "question": "问题内容",
  "answer": "答案",
  "image_path": "/path/to/image/0.png"  // ⚠️ 需要的是文件路径，不是图片对象
}
```

框架使用 `Image.open(image_path)` 来加载图片：
```python
# 在 evaluator.py 和 model_api.py 中
with Image.open(image_path) as img:
    # 处理图片
```

### 3. 为什么不能直接使用 PIL Image？

因为数据需要保存到 JSONL 文件中：
- JSON/JSONL 格式只能存储基本类型（字符串、数字、列表、字典）
- **无法直接序列化 PIL Image 对象**到 JSON
- 必须在 JSONL 中存储图片的文件路径（字符串）

### 4. 完整的转换流程

```
┌─────────────────────────────────────────────────────────┐
│ 1. 从 Arrow 缓存加载数据（本地，不联网）                │
│    datasets.load_dataset()                              │
│    ↓                                                     │
│    item["image"] = <PIL.Image object>  # 内存中的对象   │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│ 2. 将 PIL Image 保存为本地文件                          │
│    image.save("/path/to/image/0.png")                  │
│    ↓                                                     │
│    图片保存到磁盘                                        │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│ 3. 在 JSONL 中存储文件路径                              │
│    {"image_path": "/path/to/image/0.png"}              │
│    ↓                                                     │
│    保存到 finmme_converted.jsonl                        │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│ 4. evaluate_py 框架读取 JSONL                           │
│    image_path = item["image_path"]                     │
│    img = Image.open(image_path)  # 从文件路径加载图片   │
│    ↓                                                     │
│    进行评测                                              │
└─────────────────────────────────────────────────────────┘
```

## 总结

- ❌ **不需要联网下载**：数据已经在本地 Arrow 缓存中
- ✅ **需要保存图片**：因为 evaluate_py 需要文件路径，而 JSONL 无法存储 PIL Image 对象
- ✅ **一次性工作**：图片只需要保存一次，后续可以直接使用保存的路径

## 是否可以避免保存图片？

理论上可以，但需要大幅修改 evaluate_py 框架：
- 让 evaluate_py 支持直接从 Arrow 格式读取
- 或者在运行时直接传递 PIL Image 对象
- 但这些修改违反了"不修改 evaluate_py 框架"的要求

因此，保存图片是最简单、最符合现有框架的解决方案。
