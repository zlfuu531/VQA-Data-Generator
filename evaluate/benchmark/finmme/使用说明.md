# FinMME 数据集评测使用说明

## 快速开始

### 1. 一键运行（推荐）

```bash
cd /home/zenglingfeng/qa_pipline12-7/evaluate/benchmark/finmme
./run_eval_finmme.sh
```

脚本会自动：
- 检查并转换 FinMME 数据（如果尚未转换）
- 调用 evaluate_py 框架进行评测
- 将结果和日志保存在本文件夹下

### 2. 自定义配置

通过环境变量自定义配置：

```bash
# 指定模型
export EVAL_MODELS="qwen3-vl-32b-thinking"

# 指定用户画像（可选：expert, retail, beginner, expert_cot）
export PROFILES="expert"

# 测试模式（限制 100 条数据）
export LIMIT="100"

# 运行
./run_eval_finmme.sh
```

## 文件说明

### 核心文件

- **`run_eval_finmme.sh`** - 主评测脚本（一键运行）
- **`convert_data.py`** - 数据转换脚本（自动调用，也可单独使用）
- **`data_mapping.py`** - 字段映射配置

### 自动生成的文件

- **`finmme_converted.jsonl`** - 转换后的数据文件
- **`outputs/`** - 评测结果输出目录
- **`logs/`** - 评测日志目录
- **`images/`** - 图片保存目录

## 字段映射详情

### 1. question_type 映射

FinMME 使用英文题型，需要映射到中文：

| FinMME (英文) | evaluate_py (中文) |
|--------------|-------------------|
| single_choice | 单选题 |
| multiple_choice | 多选题 |
| numerical | 问答题 |

### 2. options 转换

FinMME 的 options 是字符串格式，需要转换为字典：

**输入（字符串）：**
```
"A: 3QFY22 to 3QFY23\nB: 2QFY20 to 2QFY21\nC: 4QFY23 to 1QFY24\nD: 1QFY22 to 4QFY22"
```
或
```
"A: 16% B: 20% C: 11% D: 15%"
```

**输出（字典）：**
```json
{
  "A": "3QFY22 to 3QFY23",
  "B": "2QFY20 to 2QFY21",
  "C": "4QFY23 to 1QFY24",
  "D": "1QFY22 to 4QFY22"
}
```

转换脚本会自动识别两种格式（换行分隔或空格分隔）。

### 3. 其他字段

- `id`/`idx` → `question_id`
- `question_text` → `question`
- `answer` → `answer`（直接使用）
- `image` → `image_path`（保存为本地文件）
- 其他字段（`knowledge_domain`, `unit`, `tolerance` 等）原样保留

## 常见问题

### Q1: 首次运行很慢？

A: 首次运行需要：
1. 转换数据（约 11,099 条）
2. 保存图片（约 400+ MB）
3. 这需要一些时间，请耐心等待

### Q2: 如何只评测部分数据？

A: 使用 `LIMIT` 环境变量：
```bash
export LIMIT="100"  # 只评测前 100 条
./run_eval_finmme.sh
```

### Q3: 如何评测多个模型？

A: 使用逗号分隔：
```bash
export EVAL_MODELS="qwen3-vl-32b-thinking,InternVL3_5-30B-A3B"
./run_eval_finmme.sh
```

### Q4: 如何重新转换数据？

A: 删除转换后的文件，重新运行：
```bash
rm finmme_converted.jsonl
./run_eval_finmme.sh
```

或手动转换：
```bash
python convert_data.py --output finmme_converted.jsonl
```

### Q5: 输出文件在哪里？

A: 结果文件在 `outputs/{profile}/{model_name}/finmme_eval_results.jsonl`，例如：
- `outputs/expert/qwen3-vl-32b-thinking/finmme_eval_results.jsonl`

## 配置参数说明

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| EVAL_MODELS | 要评测的模型（逗号分隔） | qwen3-vl-32b-thinking |
| PROFILES | 用户画像（逗号分隔） | expert |
| LIMIT | 限制评测数量 | 空（全部） |
| WORKERS | 并发线程数 | 24 |
| LOG_LEVEL | 日志级别 | INFO |
| RESUME | 断点续跑 | true |
