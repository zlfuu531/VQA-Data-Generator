# 输入数据格式要求

## 支持的格式

- **JSON** (`.json`): 数组格式 `[{...}]` 或包含 `items` 字段的对象 `{"items": [{...}]}`
- **JSONL** (`.jsonl`): 每行一个 JSON 对象
- **CSV** (`.csv`): 表头为字段名，数据从第二行开始
- **Excel** (`.xlsx` / `.xls`): 表头为字段名，数据从第二行开始

## 必需字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `question_id` 或 `id` | 字符串 | 问题ID（唯一标识） |
| `question` | 字符串 或 字典 | 问题内容。单轮为字符串，多轮为字典 `{"round1": "...", "round2": "..."}` |
| `answer` | 字符串 或 字典 | 答案内容。单轮为字符串，多轮为字典 `{"round1": "...", "round2": "..."}` |

## 可选字段

### 图片相关

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `image_id` | 字符串 | 图片ID |
| `image_path` | 字符串 或 列表 | 图片路径。多张图片：JSON/JSONL用逗号分隔字符串或列表，CSV/Excel用分号分隔字符串 |
| `image_urls` | 列表 或 字符串 | 图片URL列表。CSV/Excel格式可用分号分隔字符串 |
| `image_type` 或 `type` | 字符串 | 图片类型 |
| `original_image_path` | 字符串 或 列表 | 原始图片路径（格式同 `image_path`） |

### 问题相关

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `question_type` 或 `gen_type` | 字符串 | 问题类型 |
| `options` | 字典 或 null | 选项（选择题用）。JSON/JSONL格式为字典；CSV/Excel格式可用字典JSON字符串，或使用选项列（见下方说明） |
| `qa_make_process` 或 `process` | 字符串 或 字典 | 问题生成过程 |
| `round` | 整数 | 轮次（多轮对话格式2使用，用于合并多行数据） |

### 分类字段（用于统计）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `scenario` | 字符串 | 场景分类 |
| `capability` | 字符串 | 能力分类 |
| `difficulty` | 字符串 | 难度分类 |
| `source` | 字符串 | 来源分类 |

## 完整示例

### 示例1：JSON 格式（单轮，包含所有字段）

```json
[
  {
    "question_id": "q001",
    "id": "q001",
    "image_id": "img_001",
    "image_path": "/path/to/image1.jpg,/path/to/image2.jpg",
    "image_urls": ["https://example.com/img1.jpg", "https://example.com/img2.jpg"],
    "image_type": "chart",
    "type": "chart",
    "original_image_path": ["/path/original/img1.jpg"],
    "question": "这张图表显示了什么趋势？",
    "question_type": "visual_qa",
    "gen_type": "visual_qa",
    "options": {
      "A": "上升趋势",
      "B": "下降趋势",
      "C": "平稳趋势",
      "D": "波动趋势"
    },
    "answer": "A",
    "qa_make_process": "基于图表分析生成的问题",
    "process": "基于图表分析生成的问题",
    "scenario": "图表识别",
    "capability": "视觉理解",
    "difficulty": "medium",
    "source": "benchmark_v1"
  }
]
```

### 示例2：JSONL 格式（多轮格式2，包含所有字段）

```jsonl
{"question_id": "q002", "id": "q002", "image_id": "img_002", "image_path": "/path/img1.jpg", "image_urls": ["https://example.com/img1.jpg"], "image_type": "table", "type": "table", "original_image_path": "/path/original/img1.jpg", "question": "第一轮问题：这个表格的第一行数据是什么？", "question_type": "table_qa", "gen_type": "table_qa", "options": null, "answer": "第一行数据是...", "qa_make_process": "第一轮生成过程", "process": "第一轮生成过程", "round": 1, "scenario": "表格理解", "capability": "数据提取", "difficulty": "hard", "source": "benchmark_v2"}
{"question_id": "q002", "id": "q002", "image_id": "img_002", "image_path": "/path/img2.jpg", "image_urls": ["https://example.com/img2.jpg"], "image_type": "table", "type": "table", "original_image_path": "/path/original/img2.jpg", "question": "第二轮问题：根据上一轮的数据，计算平均值是多少？", "question_type": "table_qa", "gen_type": "table_qa", "options": null, "answer": "平均值是...", "qa_make_process": "第二轮生成过程", "process": "第二轮生成过程", "round": 2, "scenario": "表格理解", "capability": "数据计算", "difficulty": "hard", "source": "benchmark_v2"}
```

### 示例3：CSV/Excel 格式（包含所有字段）

#### 方式1：使用 options 字段（JSON字符串）

| question_id | id | image_id | image_path | image_urls | image_type | type | original_image_path | question | question_type | gen_type | options | answer | qa_make_process | process | round | scenario | capability | difficulty | source |
|-------------|-----|----------|------------|------------|------------|------|---------------------|----------|----------------|----------|---------|--------|-----------------|---------|-------|----------|------------|------------|--------|
| q003 | q003 | img_003 | img1.jpg;img2.jpg | https://example.com/img1.jpg;https://example.com/img2.jpg | diagram | diagram | original1.jpg;original2.jpg | 这个流程图的主要步骤是什么？ | flow_qa | flow_qa | {"A":"步骤1","B":"步骤2","C":"步骤3","D":"步骤4"} | B | 基于流程图分析 | 基于流程图分析 |  | 流程理解 | 逻辑推理 | easy | benchmark_v3 |

#### 方式2：使用选项列（推荐，更直观）

| question_id | question | answer | option_A | option_B | option_C | option_D | image_path | scenario | capability | difficulty |
|-------------|----------|--------|----------|----------|----------|----------|------------|----------|-------------|------------|
| q004 | 这张图表显示什么趋势？ | A | 上升趋势 | 下降趋势 | 平稳趋势 | 波动趋势 | chart.jpg | 图表识别 | 视觉理解 | medium |
| q005 | 这个表格有多少行？ | B | 10行 | 20行 | 30行 |  | table.jpg | 表格理解 | 数据提取 | easy |

**注意**：
- CSV/Excel 中多图片路径用**分号**分隔：`img1.jpg;img2.jpg`
- JSON/JSONL 中多图片路径用**逗号**分隔字符串或列表：`"img1.jpg,img2.jpg"` 或 `["img1.jpg", "img2.jpg"]`
- CSV/Excel 中 `options` 字段支持两种方式：
  - **方式1**：使用 `options` 列，值为 JSON 字符串格式：`{"A":"选项A","B":"选项B"}`
  - **方式2**：使用选项列（推荐），列名格式为 `option_A`、`option_B`、`option_C` 等，空选项列会被自动忽略
- 如果同时存在 `options` 字段和选项列，优先使用 `options` 字段
- CSV/Excel 中多轮对话需要多行，通过 `round` 字段区分（如示例2）

## 注意事项

1. **ID字段兼容**：`id` 和 `question_id` 都可以作为问题ID，优先使用 `question_id`
2. **多轮对话**：支持两种格式
   - 格式1：单行，`question` 和 `answer` 为字典
   - 格式2：多行，通过 `round` 字段区分，相同 `id` 的多行会自动合并
3. **图片路径**：如果同时提供 `image_path` 和 `image_urls`，优先使用 `image_path`；如果只有 `image_urls`，会使用第一个 URL 作为 `image_path`
4. **空值处理**：空字符串、`null`、`None`、`nan` 都会被识别为空值
5. **扩展字段**：除上述字段外，其他字段会被保留，便于后续扩展使用
6. **选择题选项**：
   - JSON/JSONL格式：`options` 字段为字典，如 `{"A": "选项A", "B": "选项B"}`
   - CSV/Excel格式：支持两种方式
     - 方式1：`options` 列为JSON字符串：`{"A":"选项A","B":"选项B"}`
     - 方式2：使用选项列（推荐），列名格式为 `option_A`、`option_B`、`option_C` 等
   - 空选项列会被自动忽略，不会包含在最终的 `options` 字典中
   - 如果同时存在 `options` 字段和选项列，优先使用 `options` 字段
